# 現在の編成が全員へ与えるボーナス

`orchestra-6`。既定は強め。戦闘開始前に「なし / 控えめ / 強め」を選ぶ。技・武器・人数・枠数は同じ。

| ロール | 控えめ・一人      | 強め・一人 | 重複 |
| ------ | ----------------- | ---------- | ---- |
| A      | HPダメージ +10%   | +25%       | 加算 |
| B      | チェイン上昇 +15% | +30%       | 加算 |
| D      | 被ダメージ ×0.90  | ×0.80      | 乗算 |
| S      | ATB蓄積 +7.5%     | +15%       | 加算 |

生存中の仲間が現在装備している武器のロールを数え、本人を含む全員へ適用する。控えの武器、隊列、選択キャラは集計条件にしない。特定の人数・組み合わせへの追加能力、ロールレベル、武器別のボーナス量は導入しない。

攻撃のHP・チェイン倍率は技の実行開始時にActionへ保存する。予約後、開始までに編成を変えれば開始時の倍率を採用する。開始後の変更では保存値は変わらない。Dは敵の一撃が当たる時点の編成を参照する。同時に着弾する範囲攻撃は全対象で同じ倍率を使い、その一撃でDが倒れた場合は次の攻撃から軽減がなくなる。

Sは各1/60実秒tickの開始時に成立していた編成を使い、戦闘時間の経過ぶんだけ全員のATBを蓄積する。そのtick末尾で成立した武器変更は次のtickから反映する。技・硬直・移動・状態効果・集中力の時計は加速せず、即時補充もしない。全員の蓄積を先に計算し、味方ID順によってSの恩恵が変わることを防ぐ。攻撃・移行の解決順は従来どおり味方ID順→敵ID順。

戦闘中はATB帯へ4倍率をまとめて表示し、オプティマ候補には成立後の倍率を表示する。実験室の「比較用の敵HP倍率」は戦闘速度を揃える比較専用で、攻撃力・行動時間には影響しない。

```sh
npm run sim -- --policy tactician --bonus none --dir artifacts/bonus-none
npm run sim -- --policy tactician --bonus strong --enemy-hp 1.5 --dir artifacts/bonus-adjusted
```

倍率はユーザーのデモ案。FF13の数値の移植ではない。参照した[RTAGamersのロールボーナス説明](https://rtagamers.com/rpg/ff13/)では本人と味方を区別するが、本デモでは本人の専門性を技に残し、編成ボーナスは全員同じ倍率にする。

旧 `orchestra-5` のスナップショット／リプレイには攻撃開始時の倍率がなく、今回の保存形式へは読み込まない。過去のテンポ・行動入力実験の資料は当時のバージョンの記録として残す。
