# 二重対象・直接操作・ブレイク表示

2026-09-08、`orchestra-15`。現在の入力と表示の仕様。以前の[対象パレット導入](sequence-palette.md)、[手動操作・AI鑑賞](live-controls.md)、[パッドUI](pad-ui.md)は旧版の設計・検証記録として残す。

## 基本操作

攻撃対象と支援対象を同時に保持する。技ボタンは対応する側の表示中の相手へ、一押しで1件の下書きを追加する。右スティックが敵側にあっても、回復・防護は保持している支援対象へ入る。技の追加では編集側を切り替えない。防御は常に操作キャラ自身へ入る。

下書きは自動実行せず、行動開始で見えている一組だけを確定する。現在の一手と最後の硬直を終え、確定列全体の必要ATBが貯まったら実行を始める。既存の確定列、下書き、入力中の対象候補は別の状態である。

| 防御の顔ボタン：Xbox Y / PS △ / Switch X   | 自分への防御                                    |

| LB・RB / L1・R1 / L・R                     | 操作キャラの交代指示                            |
| 左スティック                               | 駒の配置に沿う対象選択。メニューでは項目選択    |
| 右スティック左・右                         | 味方・敵のどちらの対象を選び直すか切替          |

戦術停止は廃止し、`TimeMode` は `normal` / `slow` のみとする。スローは0.25倍、開始時4・実時間毎秒4の集中力を消費する。メニューは時間を止めない。休憩は戦場を覆い、戦闘と集中力の進行を止める。タブ離脱・ゲームパッド切断でも休憩する。

キーボードは `Z`基本、`X`主力、`C`防御、`H`開始、`B`後続取消、`J`後列、`K`前列、`R`前後切替、`W`武器、`U`次のオプティマ、`Space`スロー、`P`休憩。`I` / `T`から補助を開く。`V`は救急薬、`L`はログ、`A/S/D/G`は指定オプティマ、`7/8/9`は一括隊列。Tabで移動したボタンやヘルプはEnter・Spaceで通常どおり決定できる。

### 移動と武器の時間

直接の移動・武器変更は下書きや確定列の手数・ATB枠を使わない。下書きが満杯でも補助メニューを含む直接経路から指示できる。移動済みの列と同じ宛先を押し続けても、新しい移動を重ねたり進捗をリセットしたりしない。

移動は入力時に受け付け、次の戦闘更新から現在の技や硬直と並行して進む。既定の移動時間0.85戦闘秒を維持し、所属列が変わるのは完了時。実行中の技の対象、武器、開始時の攻撃補正、支払い済みATB、硬直を変更しない。

個人の武器変更は直接指示し、実行中の技と硬直を終えた安全な区切りから既定0.65戦闘秒で切り替える。変更後に使用不能になる下書き・確定予約の技は既存の依存解除で取り除く。すべての下書きを無条件に保持する仕様ではない。

オプティマは全経路で3人の武器枠だけを変更する。隊列を伴わない。一括隊列と個別移動は独立して指示する。旧保存値の `uiMode: linked` を互換認識する場合も、現在の操作では分離表示・武器のみのオプティマとして扱う。実験室から新しく一体型を選ぶ経路は設けない。

## 対象の状態と印

`BattlePad` はパーティー共通の `candidates.ally` / `candidates.enemy` と、編集側を示す `candidateSide` を持つ。操作キャラは戦闘Stateの `selected` に保持する。戦闘の開始・新しい遭遇では現在の操作キャラと生存中の敵から初期対象を決める。以降のキャラ・武器・オプティマ変更では二つの対象を保持する。保持対象が戦闘不能・不在になったときだけ、同じ陣営の生存者へIDの昇順で自動切替する。編集側は維持し、元の相手が復帰しても自動では戻さない。

| 意味               | 表示                                       |
| ------------------ | ------------------------------------------ |
| 支援対象           | 足元の丸環                                 |
| 攻撃対象           | 足元の角形照準                             |
| 操作キャラ         | 頭上の下向きの印                           |
| 選び直している対象 | 駒を囲む四隅の枠                           |
| 対象不在           | 同じ陣営の生存者へ印を移す                 |
| 技の宛先           | 戦場の印、ボタンのtitleと読み上げ           |
| 列技の範囲         | ボタンのtitleと読み上げに列と人数           |
| 入力成功           | 技アイコンが下書きへ移動し、技が残る       |

技名・キャラ名は識別用として残す。「攻撃対象」「支援対象」「変更中」「下書きに追加」の常時説明文は、戦場の印・入力結果へ置き換える。詳細な意味は任意の「？」ヘルプ、title、読み上げ用の名前と通知へ残す。色だけでは区別しない。

通常のパレットはネイティブbuttonのグループとする。二つの保持対象を `aria-pressed`、編集先を別の属性と四隅で表現し、ブラウザーのキーボードフォーカスは独立させる。一つの単一選択listboxへ二つの選択を詰め込まない。薬の明示対象選択では従来の単一選択経路を使う。

### 対象不在からの自動切替

保持対象が倒れたら同じ陣営の生存者へ切り替え、次の技入力でその相手への下書きを1件追加する。再押下による確認は不要。切替だけでは技を追加しない。

下書き・確定予約・未着弾の行動でも対象不在を検知して切り替える。対象が存在する限りは固定し、不在時は同じ陣営のIDが最も小さい生存者を選ぶ。範囲技の列が空なら、生存者がいる列へ変更する。技の開始時刻・武器・攻撃補正・支払い済みATB・硬直を変えず、連続行動も接続する。着弾済みの行動は書き換えない。キャラ交代は明示した交代先への操作なので、自動差替えの対象外。

対象になれる生存者がいない、容量不足、交代待ち、操作キャラの戦闘不能などでは入力不可の印と読み上げ理由を返す。敵の全滅による戦闘終了時は従来どおり予約を片付ける。

### 追加済みの対象

単体技は個体ID、列技は追加時の選択個体の所属列を保存する。追加後の対象選択は既存の下書き・確定列・発動中の技を変更しない。列技は保存された列の生存者へ作用し、列が空になった場合にだけ対象がいる列へ切り替える。コマンドボタンと予約欄に対象の肖像は表示しない。

防御の対象は操作キャラ自身であり、保持中の支援対象を上書きしない。仲間AIは手動の対象ペアを参照せず、ロールと戦況から独立して判断する。

## ブレイク中のチェイン

200%で12秒間ブレイクする。ブレイク後も技・編成・位置によるチェイン加算を続け、上限は500%。チェインの値を100で割った倍率が次の攻撃のダメージへ掛かる。例えば220%は×2.20で、追撃して250%へ伸ばすと以降は×2.50になる。ブレイク中はチェインが減衰せず、追撃で残り時間を延長しない。終了時に100%へ戻る。これらの戦闘計算は既存仕様を維持し、上限値をルール定義と保存検証で共有した。

敵の駒にパーセント・倍率・チェインゲージを表示し、ブレイク残り秒数は別のゲージで表示する。ブレイク後も倍率の上昇と残り時間を同時に確認できる。

## タイムライン

`Y` または戦闘画面の「タイムライン」で、過去の場面を閲覧して再開できる。途中セーブ・印と独立した自動記録で、このプレイ中の2連戦と分岐を保持する。詳細は[戦闘タイムライン](battle-timeline.md)を参照。

## 同時入力と反復

左スティックの対象変更、武器、オプティマ、キャラ交代、前後移動と、技・防御・行動開始が同じポーリングに入った場合、変更側を先に扱う。そのポーリングの技・開始は受け付けず、入力不可の印と再押下の案内を出す。拒否した押下も消費し、押しっぱなしで次のフレームへ持ち越さない。

右スティックによる編集側だけの切替は保持対象を変えないため、技と同じポーリングでも処理できる。対角入力は方向を一つに絞る。技・開始・取消・直接変更・時間切替は押下の立ち上がりだけを使い、方向選択だけをリピートする。

標準ボタンに余裕がない場合は「十字キーで選択」プリセットを使える。直接変更の項目を補助メニューへ移し、アナログ軸なしで全操作へ到達させる。設定は `orchestra-gamepad-v7`。v1〜v6の物理番号と軸設定を基に役割を移し、重複割当を拒否する。

## 描画・保存・検証

入力時の技アイコン移動は420実ミリ秒のUI演出で、戦場の命中・回復とは結びつけない。下書きへの追加でHP・防護は変化しない。戦闘エフェクトは引き続きコアの実際の解決結果から描く。`prefers-reduced-motion` では入力の飛翔・拡大・カーソル移動を止め、同じ印と下書きの最終状態を残す。

対象不在時の処理を変更したため、ルール版を `orchestra-15` に更新する。旧版の途中Stateと入力再生を現在の規則へ混ぜて再開しない。印の閲覧と遭遇開始からの比較は維持する。現行版では直接移動・武器・オプティマ・スローと下書き・取消を含む入力再生が、保存したStateと一致することを検証する。対象ペアはUI状態として印に保存され、ゲームパッド設定の版とは別に扱う。

機械検証はコア・入力・対象表示の単体テストと、Chrome上の仮想Xbox / PlayStation / Switch Pro、十字キー選択、マウス・キーボード操作を使う。敵側編集中の支援追加、対象死亡時の自動切替、生存中の宛先固定、満杯時の直接移動、同時押下、設定移行、休憩・切断、音とミュート、AI鑑賞、保存復帰を対象とする。1366×752、1440×900、390×844の配置と動きを減らした表示も確認する。

物理ゲームパッドの接続と実際の押しやすさ、スクリーンリーダー実機、初見のアイコン理解率、誤操作率、継続プレイでの疲労は未検証。仮想入力での機械検証と人間の操作感を区別する。過去のAI性能比較・戦闘バランスの数値は今回再測定していない。
