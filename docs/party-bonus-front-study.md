# 前列補正を含めた編成ボーナス比較

2026-09-07。`orchestra-7 / policies-3 / queue-policy-3 / runner-5`。全職の前列威力・チェイン×1.25、開始時確定、同じ位置補正を使う編成評価を含む。

本試行12,000戦＋速度較正160戦、**12,160戦すべて最終状態のリプレイ一致、入力拒否0**。実行と結果生成は69.967秒。seed 1307〜1311、5セット、強度1〜10、1ケースは2連戦まで・最大240実秒。[集計・ソースハッシュ](party-bonus-front-results.json)、[全12,000戦の生データ](party-bonus-front-runs.jsonl.gz)。

## 標準持ち込み

各欄250戦の勝利数。既存の予告対応・時間操作併用と新2方針は予約3手、他の既存方針は従来方式。装備方針は旧6方針が従来交換、新2方針は対応重視／攻勢特化。

| AI | なし | 控えめ | 強め | 強め・速度比較 | 前列拡張前の強め |
| --- | ---: | -----: | ---: | -------------: | ---------------: |
| 自動行動任せ | 65 | 67 | 71 | 61 | 72 |
| 攻撃優先 | 34 | 40 | 50 | 40 | 44 |
| 均衡型 | 66 | 71 | 83 | 75 | 86 |
| 後列維持 | 75 | 75 | 87 | 72 | 87 |
| 予告対応 | 111 | 125 | 131 | 121 | 131 |
| 時間操作併用 | 117 | 134 | 131 | 126 | 135 |
| 編成適応 | 98 | 109 | 119 | 108 | 116 |
| 攻勢特化 | 103 | 110 | 125 | 114 | 125 |

前列拡張前は[orchestra-6の保存結果](party-bonus-study.md)。v7では前列倍率の対象範囲だけでなく、位置倍率の確定時点とAIの出力評価も更新した。この差を倍率だけの効果とは断定しない。高速化については別途、同一v7条件で入力列と結果の一致を確認している。

速度比較は既定ABS・自動行動任せ・装備維持・鐘楼で、別seed 9101〜9105を使って較正した。なし81.85秒、強めで敵HP×1.40なら81.73秒（約−0.14%）。画面の「強め・速度比較」も×1.40へ更新した。全AIや全セットの所要時間を揃えた設定ではない。

## 傾向

- 全員前列を基本にする攻撃優先は、強め44勝→50勝。後列維持は87勝のまま。前列の見返りは増えたが、攻撃優先は退避や防御を扱う予告対応131勝には届かない。
- 強めの勝利数は全方針で「なし」を上回る。一方、時間操作併用は控えめ134勝に対し強め131勝。倍率・ATB供給が上がると判断や行動の順序も変わるため、固定AIでの成績は単調に増えない。
- 編成適応はDを戦闘時間の14.5%、Sを21.7%使用し、防護技1,023回、回復技1,355回。D/Sを倍率のためだけに出しているわけではない。予告対応はDを使わず131勝であり、この試行からD必須とは言えない。
- 攻勢特化のS稼働は3.3%。S常駐だけが有効な編成でもない。
- 新AIが前列にいる時間は、生存者の延べ時間に対して編成適応12.9%、攻勢特化13.2%。現状は予告への退避を重視し、安全を評価して自発的に前列へ戻る専用判断は持たない。前列補正を最大限使うAIの上限までは探索できていない。

同じ攻勢装備の2AIは、前回同様に結果が一致した。回復・防護を持たなければ、両方針の重みの違いが実際の選択へ出ない。自動装備の編成適応は強め111勝で、既定維持118勝を下回った。装備評価は改善余地があり、全武器探索を最適解として扱わない。

## 観測した攻略上限

標準持ち込み・強めで、少なくとも1seedが勝った最高強度。

| セット | 最高強度 | その強度の代表AI |
| ------ | -------: | ---------------- |
| 鐘楼の関門 | 7 | 予告対応 2/5 |
| 双盾の城門 | 7 | 時間操作併用 4/5 |
| 交差砲火 | 5 | 予告対応 4/5 |
| 追撃の猟兵 | 5 | 時間操作併用・攻勢特化 各4/5 |
| 灰雨の消耗戦 | 6 | 攻勢特化 3/5 |

強度8〜10はこの条件の8方針では未勝利。前回から最高強度は変わらないが、交差砲火の予告対応は強度5で1/5→4/5へ改善した。5seedの探索結果であり、人間や別のAI・装備による攻略を否定するものではない。

```sh
npm run sim:bonuses -- --seeds 5 --dir artifacts/new-front-bonus-study
```

実行時のソース不変、入力拒否、リプレイ一致、生データのSHA256を検証。代表リプレイと判断・イベントの15件は `artifacts/party-bonus-front/`。前列拡張前の結果は上書きせず保存した。
