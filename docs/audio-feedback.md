# 操作と戦闘の効果音

Web Audioの短い合成音を使用する。予約追加／取消／移動／武器変更／オプティマ／交代／防御／薬／時間操作／休憩／入力拒否に別の音型を割り当てた。対象や項目を動かすと軽い音、決定や取消では別の音を返す。操作結果は短いテキストでも表示する。

戦闘には攻撃命中、被弾、回復、防護、予告、ブレイク、勝敗の音を付ける。AI鑑賞ではプレイヤー操作音を連打せず、戦闘イベントを鳴らす。同音の短時間連続と同時発音数を制限し、4倍速でも音が無制限に重ならない。

上部の「音ON／音OFF」で切り替える。音声の開始が必要なブラウザでは「音を開始」をクリックする。音量は実験室で調整でき、音量とミュートをこのブラウザに保存する。ミュートで現在鳴っている音も停止する。読み込んだ過去のログをまとめて発音せず、保存状態を戻した後の新しい出来事だけを鳴らす。

音型の区別、発音数制限、ミュート、保存状態復元を単体テストし、Chromeの実AudioContextで発音ノードが作られることと、ミュート後に増えないことをブラウザテストする。各機器のスピーカー・ヘッドホンでの聴感や音量バランスは別途確認が必要。
