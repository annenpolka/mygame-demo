# 手動操作・戦場内の対象選択・AI鑑賞

2026-09-07、ルール `orchestra-2`。起動は `npm run dev`。

## 防御と操作中の仲間

防御は1 ATBを実行開始時に消費する。準備0.2秒の後、4秒間自分の被ダメージを半減。ATB不足でも予約でき、充填まで待つ。マウス用・パッド用の技表示、予約時刻の見積もり、AIの予約、ヘッドレス実行が同じ技定義を参照する。

手動モードでは選択中の仲間が「指示待ち」になる。ATBは充填するが、予約が空でも自分から技を使わない。実行中の技は最後まで続き、予約した技・移動・武器変更も通常どおり実行する。選択を別の仲間へ移すと、元の仲間は自動行動に戻る。選択された仲間の実行中の技を中断したり、ATBを返したりはしない。

`State.controlMode` と `control` コマンドで操作モードを記録する。画面の選択だけを理由に、AI鑑賞やヘッドレスの仲間が待機しないよう、AI実行時は全員の自動行動を有効にする。

## 戦場で対象を選ぶ

技を選ぶと、対象を選ぶ場所が横向きの戦場になる。

- 単体技は駒、列技は前列・後列を選ぶ。回復は味方、防御は自分を選ぶ。
- 選択先の輪郭・列を強調し、行動元から選択先へ線を引く。候補外の駒は薄くする。
- 戦場上部に技名・ATBコスト・対象名・決定／戻るを表示する。
- 駒・列をクリックするか、方向キーで移動し決定する。パッドでは対象を保持し、決定を押すたびに末尾へ追加する。
- 予約は各人6手。満杯・対象死亡・武器変更後の使用不能を、従来と同じコマンド検証で扱う。

PCの下段とパッド用コンソールにあった対象一覧は、戦場へ移した。パッドのボタン割当と、追加・取消だけで予約を扱う方針は維持する。

## AI鑑賞

右上の「AI鑑賞」で切り替える。開始前にAI方針・予約方式を選んで開始するか、戦闘中に操作を任せる。

| 項目     | 選択肢                                                           |
| -------- | ---------------------------------------------------------------- |
| AI方針   | 自動行動任せ、攻撃優先、均衡型、後列維持、予告対応、時間操作併用 |
| 予約方式 | 従来AI・1手、予約AI・1手、予約AI・3手                            |
| 再生速度 | 1・2・4倍                                                        |
| 鑑賞停止 | 停止／再開ボタン、Space。画面を見たまま両方の時計を停止          |

3人のHP・ATB・実行中の行動・予約と、直近の判断理由・発行した指示を表示する。第一戦後は1.2秒の間を置き、ヘッドレスと同じ武器更新（アルトの2本目を槌、リネの2本目を流星の弓）を行って第二戦へ進む。別の仲間が報酬武器を既に装備している場合は、重複装備になる変更を行わない。

方針・予約方式の切り替えではAIの判断記憶と未実行の予約をリセットする。実行中の技は続行する。「手動に戻る」でもAIの未実行予約を取り消し、通常速度で手動操作へ戻る。AIへ渡すときは人間が積んだ予約を維持し、時間操作を通常へ戻す。Escの休憩と、別タブへの移動は画面を覆う従来の休憩を使う。

`WatchPlayer` はNode専用の実行器をブラウザへ持ち込まず、既存の `createPolicy` / `createQueuePolicy` と `observe` を使う。判断は15 tick（0.25実時間秒）ごと、反応待ちは既存の0.35秒。画面のフレーム周期ではなくシミュレーションのtickに合わせて入力を発行する。倍速でも刻み・判断頻度・反応時間は変えず、同じ経路で入力を記録する。
