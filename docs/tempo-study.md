2026-09-07。変更前はコミット `aabf2b0` の `orchestra-2`、変更後は `orchestra-3`。基礎技・防御・薬を短時間に連発できる状態を改め、技の発動後にも行動時間を使うようにした。

技の効果は準備終了時に一度だけ発生する。硬直中は次の技・通常移動・武器変更を開始しないが、予約の追加と取消はできる。取消・仲間変更・手動復帰で実行中の硬直や支払いを消せない。防御は硬直中にも効果を発揮し、緊急退避の使用者は自分が退避しても硬直を支払う。

戦場・仲間一覧・パッド・マウス用コンソールに「発動まで」「硬直」と残り時間を表示する。技ボタンは発動時間と硬直時間を併記し、発動リングと硬直リングを区別した。予約時刻の見積もりは硬直を含め、AIの防御判定には効果が出る時点を返す。画面の倍速やスローを変更して通常速度を偽装する処理は追加していない。

## 測定条件

- 5セット × L1〜L10 × 10構成 × 20 seed = **10,000ランずつ、前後20,000ラン**。seedは1307〜1326。勝利は2連戦を両方突破した場合のみ。
- 10構成は6つの従来AI＋予告対応／時間操作併用の予約1手・3手。ほかの4方針は予約方式を変えても判断処理が同じなので重複実行しない。
- 敵HPは強度ごとに1.30倍、ダメージは1.40倍。味方のHP・技威力・ATBコスト・装備・共通戦利品更新は同じ。AIの判断／観測／予約方針のソースは変更前後で同一ハッシュ。
- 両条件とも上限240実秒、観測間隔0.25実秒、反応待ち0.35実秒。反応待ちは人間の実測値ではなく仮定で、既定値は観測周期により実効0.5秒になる。
- 予備実行400ラン、反応待ち1秒の追試1,500ラン（L3〜5・10 seed）、変更後の時間切れ120ランを上限480秒で追試。合計22,020ランはすべて最終状態までリプレイ完全一致、拒否入力ゼロ。
- レートは戦闘時間を分母とする。コア指示数は人間のクリック数ではない。seedを揃えても行動によって乱数の消費順が変わるため、全被弾を同一に固定した比較ではない。

## 短時間の連打はどれだけ減ったか

AIによらない確認として、ATB満タンの手動キャラ1人に同じ技を6手予約した。ほかの仲間は戦闘不能、敵は反撃しない大きなHPの標的とし、薬だけは残数に合わせ3手とした。

| 技 | 3秒以内の開始回数（前→後） | 3秒以内のATB消費（前→後） |
| --- | ---: | ---: |
| 斬撃 | 6 → 2 | 6 → 2 |
| 円弧斬り | 3 → 1 | 6 → 2 |
| 防御 | 6 → 3 | 6 → 3 |
| 救急薬 | 3 → 2 | 0 → 0 |

斬撃6手の最後の開始は2.38秒→9.60秒。満タン分を瞬時に吐き出す強さを抑えつつ、追加・取消による予約操作は維持できている。

## 攻略境界

各セル20回のうち18勝以上となった最高強度。これは測定範囲内の観測値であり、最適攻略・真の90%勝率・難度の単調性の証明ではない。「最高」は方針ごとに測った境界の最大値で、各seedに都合のよいAIを選び直して勝利数を合算してはいない。

| セット | 変更前・240秒 | 変更後・240秒 | 変更後・480秒 | 読み取れる傾向 |
| --- | ---: | ---: | ---: | --- |
| 鐘楼の関門 | L6 | L5 | L5 | 行動中に防御を予約できる方針が優位。 |
| 双盾の城門 | L6 | L4 | L5 | 防護役が複数いると長期化。時間切れを分けて読む。 |
| 交差砲火 | L5 | L4 | L4 | 両列が危険で、移動だけでは解決できない。 |
| 追撃の猟兵 | L5 | L4 | L4 | 個体追尾への防御を、攻撃中に積めるかが効く。 |
| 灰雨の消耗戦 | L5 | L4 | L4 | 回復・防御に行動時間を使い続ける持久戦。 |

240秒で時間切れだった120戦の再実行は、97勝・8敗・15時間切れ。240秒までに終結した戦いを保持し、時間切れ分だけ置き換えて480秒条件を集計した。双盾L5の従来・時間操作併用は14/20勝→18/20勝となる。交差砲火L4の後列維持は0勝・20時間切れ→20勝であり、通常攻撃だけでも攻略できるが時間がかかる例。480秒でも未決着の15戦を攻略不能とは断定しない。

### AIと予約方式の違い

1. **長い行動では、行動中に次の守りを積める価値が上がる。** 鐘楼L5の予告対応は従来1/20勝に対し、予約1手・3手は両方20/20勝。従来AIは技を選ぶ条件に「実行中の行動がない」を含むため、硬直中の防御を予約できない。既存の予約AIは硬直も含めた到着見積もりで対応する。判断ロジックを変えて強くした結果ではない。
2. **3手積めば常に強いわけではない。** 追撃L5の予告対応は予約1手11/20勝、3手7/20勝。消耗戦L5も15/20対13/20。途中で守りへ切り替える戦場では、先まで積む利点と取消・対象変化の影響が混在する。逆に双盾L5は予約1手0/20、3手10/20で、まとまった攻撃を続ける利点が出る。
3. **交差砲火は防御を増やしても押し切れない段階がある。** L5は全10構成で0/20勝。予告対応／予約3手は防御を平均24.1回開始しても第一戦で全敗する。両列への攻撃・回復・攻撃の配分が同時に必要で、手数制限がはっきり現れる。
4. **「遅いほど弱い」「スローなら必ず有利」でもない。** 同じ10 seedで反応待ちを0.35→1秒にすると、交差砲火L4の予告対応／予約1手は0/10→10/10、時間操作併用／予約1手は10/10→0/10になる。対して追撃L5は予告対応6/10→0/10、時間操作併用6/10→2/10。入力時点によって防御・中断・列技の順序や乱数消費が変わることから、固定周期との噛み合いに敏感だと解釈している。遅延を人間の操作負荷へそのまま換算はできない。

## 再実行と保存物

```sh
# 現行ルールの5セット・10強度・20 seed、最大2戦、10,000ラン
npm run sim:scenarios -- --dir artifacts/scenario-repeat

# 小さな試行
npm run sim:scenarios -- --seeds 2 --levels 1,4,5,6 --dir artifacts/scenario-pilot

# 反応待ち1秒の感度比較（1,500ラン）
npm run sim:scenarios -- --seeds 10 --levels 3,4,5 --reaction 1 --dir artifacts/scenario-reaction

# 長期戦を1つ詳しく再現（判断・全イベント・リプレイを出力）
npm run sim -- --set bulwark --level 5 --policy focus --planning queue --seed 1317 --max-seconds 480 --dir artifacts/long-battle
```

- `scripts/scenario-study.ts` は測定前後のソースハッシュを検査し、全ランでリプレイを照合する。完了済み出力への上書きは拒否する。
- `docs/tempo-study-results.json` に前後・反応待ちの全セル集計、使用設定・技時間・ソースハッシュ、連続予約プローブ、戦闘密度、480秒追試集計を保存。
- `artifacts/tempo-before-v2/`、`tempo-after-v3/`、`tempo-reaction-one/` に全ラン結果、行動密度、代表例の判断ログとリプレイ。`tempo-review/timeout-results.json` に時間切れ追試の全結果。実験ファイルはGit対象外。
- 変更前の再現には `aabf2b0` のソースと今回の `scripts/scenario-study.ts` を使う。バージョンをまたいだリプレイは比較しない。`orchestra-1` / `orchestra-2` の保存データを現行の画面には読み込めない。
- 107件の単体テストと26件のChrome E2Eが通過。連打上限・発動時点と硬直終了の区別・硬直中の防御効果・予約取消・自己退避・停止と保存再生、マウスとパッドの発動→硬直表示、敵予告、AI鑑賞と手動復帰を確認した。低いデスクトップでは予約取消画面の余白を詰め、硬直中も戦場・コマンド・ログを同時に収めた。

今回確認できたのは、行動密度と短時間のATB消費を下げ、敵味方の時間を同時に調整できたこと。実機パッドでの新しいテンポの遊び心地、初見プレイヤーの選択時間、全編成での最適性はこのヘッドレス測定だけでは判断しない。
