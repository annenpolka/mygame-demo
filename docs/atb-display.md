# 陣形と操作キャラのATB

陣形は人数・前後移動・撃破に関わらず3人分の高さを確保する。対象選択バーも通常の見出しと同じ高さに置く。前後への移動でコマンドの位置を動かさない。

操作キャラの選択を陣形直下のATB帯へ統合した。上段で仲間を選び、実行中の技と発動／硬直を確認する。下段は最大ATBぶんの分割ゲージ。予約の技は消費ATBぶんの幅を占め、2 ATBなら2枠にまたがる。技名と番号を表示し、現在の充填でどの技まで賄えるかを見せる。

0 ATBの移動・武器・薬は下の番号付き表示に置く。右の予約一覧と番号が対応する。交代が上限を超えた場合は破線の特別枠を追加する。`orchestra-16` では交代後も予約を保持するため、後続技も通常の濃さで表示し、交代後の効果発生時刻を予測する。並べ替え操作は追加しない。

参考はFF13の分割ATBと技コストの対応。原作の説明は[公式ライセンス攻略本のサンプル](https://www.piggyback.com/en/wp-content/uploads/sites/7/2020/04/FFXIII_E_SamplePages.pdf)および[RTAGamersの紹介](https://rtagamers.com/rpg/ff13/)を確認した。実行順・交代・0 ATB予約はこのデモのルールであり、原作の入力仕様の再現を意味しない。

Chromeで1366×752の陣形・ATB帯・コマンド・4手・ログ、1440×900での列対象選択、前後移動時の固定高さを確認する。携帯幅は縦スクロールし、文字を潰さず表示する。
