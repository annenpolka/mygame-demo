# 下書き・行動開始・対象パレット

2026-09-07。`orchestra-12`。添付案の三段階を実装した。戦闘コアの下書き・確定列は `20f4a02` で先に保存し、その上へ対象パレットと入力分離を接続した。ボタンが担う役割は[READMEの操作表](../README.md#操作)を参照。

## 一組を放つ

手動の入力は `draft` コマンドで下書きへ積み、`executeSequence` でその一組を確定する。必要ATBは列全体の合計。現在の行動と硬直が終わり、必要量が貯まったら先頭を開始する。支払いは各手の開始時で、未使用ATBを返却・消滅させない。初手が0 ATBの移動や薬でも、後ろの技を含めた必要量まで待つ。

現在の一手、実行中の列の残り、開始待ちの次の列、下書きを区別する。開始待ちの確定列は一組まで。確定列の未実行分と下書きを合計してコスト・手数上限を検証する。実行済みの一手は枠から外れる。実行ボタンの連打は空の下書きを複製せず、動作を停止するトグルにもならない。

同じ確定列の同技だけが0.2秒接続の候補になる。別の列は最後の硬直を払う。後続取消は確定済みの未開始分を消し、現在の一手・終了硬直・ATB・下書きを維持する。下書きの防御を準備し、攻撃の後続を打ち切ってから防御の列を確定できる。予約編集の一件取消は下書きも確定分もIDで指定し、取消済み行から別の予約を自動選択しない。

キャラ交代は既存の1 ATB・先頭優先の直接指示を継続する。交代開始時は確定済みの後続を解除し、そのキャラの下書きは残す。独立したオプティマ・一括隊列は実行ボタンを必要としない。武器変更に伴う不成立の依存技の解除は既存ルールを使う。

## 対象候補と技パレット

対象候補と基本技・主力技・防御・戻るを同時に表示する。「たたかう」の入口や対象の事前決定は挟まない。左スティックの左右でその側の候補（生存している個体のみ）を巡り、上下で敵・味方を切り替える。マウス・タッチは駒を選ぶ。敵・味方の候補はキャラごとに記憶し、使用予定の武器が変われば基本技に合う側を表示する。

基本技・主力技を押した時点で、単体技は個体ID、列技は選んだ個体がその時点でいる列へ解決して保存する。防御は自分。列そのものや空の列は選択せず、列技には「敵前列・1体」などの範囲を表示する。側が合わない場合、候補が死亡した場合は、技を入れ替えず使えない理由を出す。

候補変更は既存の下書き・確定列の対象を書き換えない。仲間AIへの集中攻撃指定は廃止し、[ロールと戦況から個別に対象を選ぶ](targeting.md)。薬のメニューは味方を選び、決定で下書きへ追加する。メニューから実行トリガーを押しても、カーソル上の項目を追加する処理はしない。

## 入力と保存

標準配置は右トリガーで行動開始、左トリガーで後続取消、戻るは従来の顔ボタン。三つの行動を残りの顔ボタンへ配置する。左スティックと十字キーを入力層で分け、十字キー左・右を時間操作、上・下を全体指示・補助へ割り当てる。補助には移動・武器変更・薬・全体指示・時間操作・ログを収録する。

十字キーで選択する別プリセットは、実行・後続取消・戻る・補助メニューボタンを固定し、四方向を選択へ使う。時間操作や補助の各機能はメニューから決定できる。リピートするのは選択移動だけ。開始・後続取消・時間変更は長押しでも一回として扱う。

設定は `orchestra-gamepad-v5`。旧設定の物理スロットを新しい役割へ移行し、カスタムの決定・戻る・肩・軸・反転を保持する。v1〜v4と未使用ボタンの補完、重複割当の拒否をテストする。

Stateにはキャラの `draft` と `sequences`、確定予約と実行中の `sequenceId` を持つ。保存・リプレイはこれらの境界を検証する。印には敵・味方の対象候補、取消済み選択、下書きと実行中の確定列も保存する。数値定義は維持し、実行処理変更の識別としてVERSIONを更新した。旧版の途中Stateは再操作せず、印の閲覧と遭遇開始からの比較を継続する。

`execution.ts` を実行と予測で共有し、確定列全体のATB待ちを予測へ含める。予測は通常速度の戦闘秒で、戦術停止中は進まない。下書きの予測は「今、行動開始を押した場合」で、既に開始待ちの確定列があるときは次の確定待ちと表示する。連結も確定列の境界を用いた条件付き予測。未来の撃破・被弾・編成変化は予測しない。

AI観測には下書きと境界のコピーを渡す。AIの `enqueue` は確定予約用で、手動の下書きを自動実行しない。AIの予約判断・到着予測から下書きを分け、下書きの将来の武器を現在のAI行動に誤用しない。容量と薬の予約残数では下書きも数える。今回、AI方針の性能比較や数値の再調整は行っていない。
