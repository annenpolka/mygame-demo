# プレイから直すための短いループ

出発点は `7674fe3`。今回の先行する区切りは、説明の整合、場面の印付け、少し前からの再操作、その記録による操作検証。交代1 ATB＋0.6戦闘秒・毎回0.8実秒の無料スロー、複数手予約、選択中は手動を基準として保つ。

## 説明の整合

軍旗の説明を緊急退避の実定義（発動0.45秒＋硬直1.15秒）から生成する。全職共通の前列威力・チェイン、後列、防護、ブレイク、時間操作の倍率を戦闘と表示で共有する。技の時間・回復量・防護時間、交代と設定変更後の集中力消費も定義から表示する。予約取消は未実行だけで、実行中の行動と支払ったATBはそのままと明示する。説明の修正に伴うバランス変更は行わない。

## 続く比較（まだ確定仕様にしない）

- 記録した引っ掛かりを、戦況の判断／待機理由の読み取り／入力数／継続的な忙しさへ分ける。実際に観測した一件ずつを直す。
- Aの単体魔法武器を一本、同ロール・同対象数・近い継続火力で比較。準備・硬直・ATBの使い分けを検証する。
- 強めを候補に、ボーナス・隊列・時間操作を一条件ずつ比較する。手動の感触をAI勝率で代用しない。
- 少数候補からのドロップと、交換で得る／失う機能、影響するオプティマを比較する。

物理魔法の防御体系、属性表、MP、ロールレベル、専用ゲージ、マップ生成、永続経済、自動修正エージェントはこの区切りへ含めない。特別な防御成功報酬、前列・D必須化、停止しないことへの過剰報酬も導入しない。

## 印から再操作する

- 戦闘中に **M / L3 /「今のところ」**。押しっぱなしでは増えず、戦闘・ATB・集中力を止めたり、戦闘コマンドを発行したりしない。
- **Shift+M /「印の一覧」**、休憩中のL3、戦闘結果・戦利品の「印の一覧」から開く。一覧中は戦場を隠し、休憩として全時計を止める。閉じると開く前の休憩状態へ戻る。
- 気持ちよかった場面と困った場面を同じ仕組みで記録し、任意の分類と300文字までのコメントを後から付ける。
- 「約3秒前から再操作」は約3**実秒**前（記録間隔は最大0.25秒）の状態を入力列から再生し、一致を確認する。遭遇をまたいでは戻さない。印の瞬間・この遭遇の最初も選べる。
- 選択中の仲間、交代待ち、ATB、発動・硬直、予約、対象、操作画面と選択位置を戻す。確認画面で準備してから「この場面から操作する」で開始する。時間操作モードも記録どおり。AI鑑賞からの再操作は、確認後に選択中の仲間を人間が操作する。
- 元の入力履歴・印は変更しない。再操作後の入力は新しい枝となり、そこで付けた印には元の印を関連付ける。同じtick内の複数入力も、入力個数で境界を区別する。
- 印はこのブラウザへ最大20件保存する。JSONで書き出し・読込も可能。重複IDは追加せず、異なる印は残す。ブラウザの保存に失敗した場合は、その旨を表示し、タブ内の印をJSON保存できる。

### 同じ版の再現と、現在のルールでの比較

数値・技・武器・共通ルールの識別情報とコアの版を記録する。説明文だけの修正では再操作できる。ルールが異なる場合は途中からの再操作を無効にし、「現在のルールで、遭遇開始から比較」を使う。再生した状態が記録と一致しない場合も、現在の戦闘を変更せずエラーを示す。

開始からの比較では、記録した武器・オプティマ・隊列・所持品・遭遇・設定を使い、HP・ATB・行動・乱数を現在のルールで初期化する。進行中の旧版Stateは移植しない。武器などが現行版で使えない場合は、検証エラーを表示して開始しない。この操作は同じ途中状態の再現とは区別する。

コアの処理順や計算ロジックを変える際は `VERSION` を更新する。数値の識別だけではロジック全体の互換性を証明できないため、再操作時にも入力再生と保存Stateを比較する。操作画面は論理的なページ・選択・対象を保存し、物理ボタンの表示は使用中の機器に合わせる。スクロール位置・動画・音声は記録対象にしない。

### 操作確認で直した箇所

対象選択の見出しには最低50pxが残り、1366×752の画面ではログの下端が780pxへはみ出していた。通常時と同じ28pxへ揃え、技説明の余白を整理した。新しい情報パネルは追加していない。
