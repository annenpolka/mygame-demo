# 編成と持ち込みを判断するAI

`policies-3 / queue-policy-3 / runner-5`。従来の6方針を残し、編成適応 `adaptive` と攻勢特化 `assault` を追加した。Web鑑賞の既定は編成適応。

3人×2武器から到達できる8通りについて、技の威力・チェイン・回復・防護、発動と硬直、ATB供給、現在のロールボーナスを計算する。HP不足や予告、ブレイク中かどうかで重みを変え（非ブレイク時は敵HPに応じてチェインの重みを増やす）、切替に必要な時間の損失も考慮する。構成変更は前回判断から4戦闘秒以上、現在の評価を12%超かつ一定量上回る場合に限る。成立待ちの武器変更を重ねない。既存オプティマと一致すれば一括指示、一致しなければ個別の武器変更を予約する。古い技予約は必要な仲間だけ取り消す。

新しい攻撃予告には既存AIと同じ0.35実秒の反応待ちを置く。敵の未公開タイマー・乱数は観測しない。列予告には退避、回避できない攻撃には防御、HPが低ければ回復や薬を使う。対象数と発動時間から単体／列技を選び、引き寄せも使う。武器で使えない技を追加しない。

開始前と戦利品時には、持ち込める6枠の各々について、元の武器か未装備の所持品への交換を探索する。他の仲間が持つ武器の再配分は探索しない。武器の重複使用はせず、各候補が作れる火力・崩し・回復・防護の幅を評価する。対応重視は回復・防護も評価し、攻勢特化は攻撃・崩しへ重みを置く。準備した武器から4つのオプティマを生成する。

Webとヘッドレスは同じ準備・判断を使う。装備方針は従来交換／維持／対応重視／攻勢特化から独立に選べる。戦闘中に変更した装備方針は次の準備時に適用する。新AIの切除比較は未対応のため `--ablation none` のみ受け付ける。

```sh
npm run sim -- --policy adaptive --planning queue --loadout adaptive --bonus strong --dir artifacts/adaptive
npm run sim -- --policy assault --planning queue --loadout assault --full-inventory --bonus strong --dir artifacts/assault
```

`--full-inventory` は実験室と同じ全武器追加コマンドを開始前に記録する。通常のランで未入手の武器を使うため、標準持ち込みと分けて比較する。既存の6方針は従来交換を既定とする。武器・オプティマ・技・取消をすべてリプレイへ記録する。

`sim:limits` の固定ハッシュは今回のAI版へ更新した。以前のレポートにある勝率や限界は当時の版の記録であり、今回の結果へ読み替えない。現行の観測ではATB供給速度にSを反映し、元の蓄積速度も別に渡す。`roleSeconds` は3枠の役割履歴、`activeRoleSeconds` は戦闘不能を `-` として除いた実際の編成ボーナスの稼働時間。

予備試行では、強め条件の新AIが直撃火力へ偏り、崩しを使わない傾向が見えた。敵HPに応じたチェイン評価と、持ち込みの崩し能力の重みを修正した。最終評価は別の本試行として行い、予備試行の結果を混ぜない。

同じ状態への重複評価を減らした高速化は、判断結果を変更しない。[同条件での計測](headless-performance.md)を参照。
