# 行動入力・交代・陣形表示

2026-09-07、`orchestra-5`。敵味方の技の発動・硬直、ATB回復速度は[テンポ調整](tempo-study.md)を引き継ぐ。

## 一押しの操作

| 操作                             | パッドのコマンド画面    | マウス用画面のキー |
| -------------------------------- | ----------------------- | ------------------ |
| 前後移動を末尾へ積む             | ←                       | R                  |
| もう一方の武器枠へ切り替える予約 | →                       | W                  |
| 未実行の先頭1件を取消            | ○ / B                   | Backspace / Delete |
| 防御を末尾へ積む                 | ↓                       | Cで自分を選択      |
| 予約一覧・個別取消               | R3                      | 予約行の取消ボタン |
| 交代を先頭へ積む                 | L1 / R1、LB / RB、L / R | Q / E、1〜3        |

移動と武器切替は、現在の位置・武器に加えて既存予約の到達先を見て反対側へ積む。連続入力なら前後・武器枠1/2が交互になる。変更先の役割と機能をボタンへ表示する。方向キーを押し続けても、コマンド画面では予約を連打しない。選択画面の方向移動はリピートする。

FF13の[公式PC版コントローラー操作表](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/292120/manuals/Controller_Keyboard_US.pdf)で、戦闘中のBボタンがキャンセルであることを確認し、取消／戻るの割当に反映した。「未実行の先頭1件だけを取り消す」は今回指定されたデモの契約であり、原作がその単位で取り消すと確認できたわけではない。選択画面では○／Bは「戻る」。実行中の発動や硬直は取り消さず、消費済みATBも返さない。武器予約を取り消して後続技が使えなくなった場合は、従来どおりその依存技も解除してログへ残す。

## 予約容量と交代

通常の予約は合計コストが最大ATBまで。移動・武器・薬など0 ATBの行動も1手と数え、手数も最大ATBと同じ上限にする。既定4、実験室とCLIの `--atb-max` で2〜8に変更できる。実行中の行動は未実行枠に含まず、現在のATBが不足していても先行入力できる。

交代は例外として、**1 ATB・0.6戦闘秒の行動を常に先頭へ積む**。満杯でも1件追加でき、既定なら一時的に5 ATB・5手になれる。交代先を選び直した場合は交代予約を置き換える。

1. 現在の発動・硬直、すでに進行中の移動や武器変更を終える。
2. ATBが1に達したら交代を開始し、1 ATBを払う。この時点で操作キャラの後続予約を解除する。後続には実行時刻の代わりに解除予定を表示する。
3. 0.6秒後に操作キャラを変更する。交代先で実行中の行動は続き、交代先自身の予約は保持する。
4. 毎回0.8実秒の引継ぎスロー（×0.25）を付ける。集中力消費も再発動待ちもない。手動スロー中もこの期間の集中力を消費しない。戦術停止は利用者の指示を優先し、休憩はすべての時計を止める。

実行前に交代を取り消せば、後続は残る。交代開始後は取り消せず、交代先が倒れた場合にも消費ATBを返さない。交代開始前に交代先が倒れた場合は、交代予約だけを解除する。AI鑑賞での注視対象変更はこの手動交代と分ける。

## 陣形と編成

独立した敵ステータス列を廃止し、陣形を横いっぱいに広げた。敵の駒にはHP、チェイン、ブレイク残時間、技の予告ゲージと対象を集約する。チェインは100→200%の蓄積、ブレイク中は12秒の残時間が減るゲージになる。味方のHP・ATBも駒へ表示し、パッドの仲間選択帯から重複ゲージを外した。

「編成」から、仲間の武器枠を選び、所持武器のカードで交換する。使用中の武器は持ち主を表示する。オプティマは武器と役割のカード、一括隊列は前後列の配置図で編集する。オプティマ名は役割の組み合わせ、一括隊列名は前後の人数から自動更新し、武器交換にも追従する。

Aは削る、Bは崩す、Dは受け止める、Sは状態を整える。既存の守護騎士だけをSからDへ移した。技・数値・3人パーティー・一人2武器は変更していない。現行能力に合わせて「D｜防護」と表示し、未実装のかばう能力は追加しない。Dへの切替と前列移動は独立し、通常防御と列移動は全員が利用できる。

単体テスト134件、Chromeの全32ケースを通過した。単体テストでは上限例外、先頭取消、武器依存、ATB支払い、後続リセット、無料スロー、交代先死亡、戦闘終了、保存と再生を検証する。Chromeでは3系統の仮想パッド、変更先の役割表示、編成編集、ブレイクゲージ、2連戦、1366×752・1440×900・390×844の画面を確認する。今回の新しい割当を実機パッドで確認したものではない。
