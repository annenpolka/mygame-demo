# 戦闘タイムライン

2026-09-08。`orchestra-15`。途中セーブや手動の「印」と独立した、このタブのプレイ履歴。

## 操作

戦闘画面の「タイムライン」またはキーボードの `Y` で開く。休憩ポーズ、戦利品、勝敗結果にも入口がある。パッドは休憩画面から選択して開ける。

スライダー、前後の時点、5秒前後、最初・最新、出来事のボタンで位置を選ぶ。過去の戦場、HP・ATB・発動中の技・下書き・予約を確認できる。位置は経過だけでなく入力ごとにも区切るので、同じ時刻に追加した複数のコマンドの間へ戻れる。5秒前後の移動は通常速度の進行tickを基準にするため、スロー中は画面の戦闘秒との差がある。

閲覧中は戦闘とAI鑑賞の進行を止める。「今の戦闘へ戻る」または `Esc` は閲覧だけを閉じ、元の状態・入力列・休憩状態へ戻る。過去のプレビューは戦闘へ操作を送らない。

「ここから再開」は選んだ地点で新しく分岐する。戦闘中の地点は準備用の休憩状態に戻り、「この場面から操作する」で続ける。開始前や戦利品の地点はその画面へ戻る。AI鑑賞から戻る場合は手動操作へ切り替える。現在の履歴の最新位置なら、分岐を作らず閲覧を閉じる。

元の進行も「履歴」から選べる。過去の分岐を再び選んで再開することも可能。2戦目から1戦目へ戻れ、戦闘間の装備変更も区別する。同じタブでリトライやセーブ読み込みを行った場合は、新しいプレイとして記録し、以前の履歴も残す。

パッドは左右で時点、LB/RB相当で5秒前後、上下で履歴、決定または行動開始で再開、戻るまたはポーズで閲覧を閉じる。キーボードはスライダー上で矢印・Home・End、ボタン間はTabを使える。戦場と出来事の部分だけをスクロールでき、位置操作と再開ボタンは常に表示する。

## 保存との境界

タイムラインはブラウザのメモリだけに保持する。再読み込み・タブ終了で消える。途中セーブの作成・上書き・読み込みや、「印」の保存は行わない。既存の途中セーブは巻き戻した後も復元できる。手動セーブや外部記録の読み込み以前の場面を、タイムラインへ新しく展開する機能は含めない。

## 実装と整合性

- `Session.subscribe` は入力適用後・各シミュレーションstep後・読み込みやリセット後に観測者を通知する。購読がないヘッドレス処理の計算と入力形式は変えない。
- `BattleTimeline` は約0.25秒間隔と、入力・UI・戦闘フェーズの変化を記録する。各点にtickと適用済み入力数を持たせ、停止時刻に複数の入力がある場合も再現する。
- 約4秒間隔と戦闘フェーズの境界にStateを保持し、閲覧時は直近のStateと後続の入力だけで再現する。各点でState全体を複製し続けない。
- 再開時は初期状態からの入力再生と途中からの再現を照合してから、入力の末尾を選んだ地点で切る。元の分岐の入力・時点・Stateは書き換えない。
- 記録時の `playRules()` と現在の定義を照合する。戦闘の数値・計算・処理順は変更していないため、`VERSION` は `orchestra-15` を維持する。
