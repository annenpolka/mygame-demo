# 前列の威力と崩し

`orchestra-7`。前列の味方は全ロール・全武器でHPダメージとチェイン上昇量がそれぞれ1.25倍。ブレイクの持続時間や閾値、回復量、防護の持続時間は変更しない。敵への同じ補正は追加していない。

以前の「近接の前列威力×1.25」「Bの前列チェイン×1.25」を共通ルールへ置き換えた。既存の1.25をさらに掛けることはない。砕城の槌の前列チェイン特性×1.2は別に残り、前列のチェインは合計×1.50。後列近接の威力×0.85、後列射撃・魔法×1、後列被害×0.72は従来どおり。

攻撃側の編成ボーナスと位置・武器特性は乗算し、技を実際に開始した時点で保存する。予約後に移動してから開始すれば移動先の補正。開始後に押し出されても、その一撃の補正は変えない。Dの軽減は被弾時、敵チェインやブレイク特効・敵後列防護は着弾時に判定する。

AABの魔術師が前列で技を開始すれば、威力は基礎×1.50×1.25、チェインは基礎×1.30×1.25。陣形を変えても使える技やロールは変わらず、Dと前列も独立している。

戦場の味方前列へ「威力・崩し＋25%」を表示。編成・装備AIの出力評価も戦闘本体と同じ位置倍率を使う。攻撃可能な6武器について実ダメージ・チェインとAI評価の一致、予約移動と発動後の押し出し、回復・防護への非適用を検証する。

旧バージョンの保存では攻撃補正の意味が異なるため、`orchestra-6` 以前のスナップショット・リプレイは読み込まず、そのバージョンのコミットで再生する。
