# 個体選択とロール別AI

2026-09-07。`orchestra-12`。対象操作と味方AIの対象選択を変更した。ATB・技の威力・硬直・敵の数値は変更していない。

## 手動の対象（2026-09-08、orchestra-15へ更新）

攻撃対象と支援対象はパーティーで共有し、同時に保持する。左スティックは駒の配置に沿って対象を選び直す。右スティックの左で味方、右で敵のどちらを編集するか切り替え、保持中の宛先は変更しない。キャラ・武器・オプティマを替えても両対象と編集側を維持する。

足元の丸環が支援対象、角形が攻撃対象、外側の四隅が編集対象を示す。技には技アイコンとATBコストを表示する。対象の肖像はコマンドボタンと予約欄から取り除き、宛先は戦場の印・title・読み上げで確認する。常時表示する状態の説明文を減らし、読み上げと任意の操作ヘルプへ意味を保持する。基本技・主力技は対応する側の相手へ一押しで下書きする。自分への防御は操作キャラへ入る。

斬撃は敵ID、円弧斬りは追加時にその敵がいる列を保存する。範囲技は予約後に個体の移動を追わず、着弾時、その保存した列にいる生存者へ作用する。対象の再選択は既存の下書き・確定列を変更しない。

保持対象が倒れた場合は、同じ陣営の生存者へID順に自動切替する。下書き・確定予約・発動中の技も対象が不在なら切り替え、支払い・発動時間・連続行動を保って継続する。列が空になった範囲技は対象がいる列へ切り替える。詳しい例外と入力順は[現行操作仕様](dual-target-controls.md)を参照。

## 仲間AI

共有の集中攻撃ボタン・マーカー・Stateの `target`・`target` コマンドを削除した。対象候補を見比べる操作からAIへ指示は送らない。時間操作に使う「集中力」とAI方針「時間操作併用」は別機能なので継続する。

| ロール・技         | 主な判断                                                                                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| A                  | 一撃で倒せる敵、発動までブレイクが残る敵、Bが伸ばしているチェインの維持を重視する。後列防護と武器・編成・位置補正も見込む。                          |
| B                  | 倒し切れる敵を見ながら、未ブレイクで閾値に近い敵を優先する。同程度ならAが行動中・予約中の対象に合わせる。Aがブレイクを削っている間に別の敵を崩せる。 |
| D                  | 防護が不足している生存者から、間に合う攻撃予告、HP、前列の露出を評価する。常に前列の先頭へ掛ける挙動を廃止。                                         |
| S                  | HP83%未満を対象とし、HP不足と他の味方が発動中の回復を考慮する。同じ負傷者への回復が重なる無駄を減らす。                                              |
| 引き寄せ・押し出し | 踏ん張りや重装を確認し、実際に移せる相手と中断できる予告を評価する。                                                                                 |
| 範囲技             | 列内の生存者に対する評価を合計する。単体の代表者だけで決めない。                                                                                     |

`src/sim/targeting.ts` の純粋関数を自動行動と編成適応AIで共有する。観測できるHP・列・チェイン・予告・味方の行動だけを使い、RNGや非公開の敵タイマーは参照しない。同点はID順、列は前列を先にする。方針AIの武器・回復・退避判断はそれぞれ維持する。

発動済みの `Action.target` は対象が生存している限り固定し、不在時だけ同じ陣営の生存者へ切り替える。自動行動が作った `auto` の後続は、次の一手を開始する境界で選び直す。対象が死亡しても、別の生存者へ連続技を接続できる。手動の下書き・確定列や、方針AIが明示的な戦術として予約した対象は、後から一括上書きしない。AIの現在の対象は駒の行動表示で確認できる。
